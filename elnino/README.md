# エルニーニョモニター

リポジトリのルートで `python3 -m http.server 8000` を実行し、`/elnino/` を開きます。

「知る」の定点記録は `observations.json` に追記します。公式発表を確認してから各項目を書き込みます。次回の更新時も過去の記録を残すと、同じ項目の最新記録と履歴が表示されます。

| フィールド | 入力内容 |
|---|---|
| `series` | ENSOは `enso`、降雨は `rain`、短期予報・暑熱は `heat` |
| `published` | 出典の発表日（`YYYY-MM-DD`） |
| `period` | 観測期間または予報の対象期間 |
| `area` | 対象地域 |
| `summary` | 観測か予報かを明記した日本語の要約。比較できる場合は前回からの変化も記載 |
| `source` | 発表元の名称 |
| `url` | 発表資料のHTTPS URL |

「アクションする」の計画は同じブラウザーに自動保存されます。印刷画面からPDFに保存できます。
