# 面談打診メール

## 先に確かめること（会話にない場合だけ聞く。まとめて1回）

- 宛先（会社、役職）と差出人（誰の名前で出すか。関係のある人から出すのが原則）
- 相手との既存の関係（誰が、どの案件で）
- 使うシグナル：`signals/data/signals.json` からその会社・業種の直近の記事を自分で探し、候補を出す

## 書き方

- 本文は日本語で300字前後、英語で120語前後。スマートフォンの1画面に収める。
- 1文目は相手の会社に固有の事実（直近の発表、拠点の動き、制度変更の期日）。一般論で始めない。
- 2文目で、その事実から見える論点を1つだけ挙げる。3つ並べない。
- 持参するものを具体的に書く（例：同業5社の対応状況の比較1枚）。「情報交換」だけにしない。
- 依頼は1つ。所要時間と候補日を2つ書く。相手に候補日を出させない。
- 敬語は二重にしない（「上げられておられる」は誤り）。「拝察いたします」「喫緊の」などの常套句を重ねない。
- 件名は「会社名＋論点」で25字以内。

## 出すもの

1. 件名案を2つ
2. 本文（差出人名義のもの）
3. 差出人に送る依頼文（3行。なぜこの会社に、なぜ今か）
4. 送る前の確認：独立性・利益相反の確認、既存の担当者への一声、事実の出典

非公開の情報（目標、案件、面談メモ）はリポジトリに書かない。
