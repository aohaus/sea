# 週次シグナル・レビュー

## 手順

1. `signals/data/signals.json` の直近7日の `items` を読む。`generated_at` が2日以上前なら、データが古いことを
   最初に書く。
2. 記事を「連絡する理由になる出来事」に分ける：新規投資・増産、閉鎖・撤退・人員削減、経営陣の交代、
   M&A・提携、制度変更の期日（税・賃金・データ保護など）、事故・不祥事。
3. 会社ごとにまとめ、次の順で最大7社に絞る：(a) 出来事が経営判断を迫るものか、(b) 支援できる領域か、
   (c) 接点があるか（ユーザーが会話で示した場合のみ）。
4. 業種をまたいで3社以上に共通する話題があれば「今週のテーマ」として1つ挙げる。勉強会や寄稿の題材になる。

## 出すもの（日本語、1画面）

- **今週の3行**：何が起きたか
- **連絡する会社**（最大7）：会社／出来事（日付・媒体）／切り出しの一言／誰経由で
- **今週のテーマ**：1つ。根拠の記事を3件
- **見送り**：目立ったが連絡の理由にならないもの（理由を一言）

## きまり

- 記事にない事実を足さない。金額・人数は元記事の表記のまま。
- 会社の優先度や案件の状況は非公開。リポジトリに書かない。ユーザーの非公開コックピットがあれば、
  そこに転記する文面を出す。
