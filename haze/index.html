このページについてAbout

クアラルンプール・ペナン・ジョホールとシンガポールの大気質を、3種類の出所（A：WAQI、B：政府公式 DOE／NEA、C：モデル Open-Meteo）で比べます。2時間ごと（1日12回）・過去14日分（168点）の時系列で、ヘイズの日内変化と出所ごとの違いを見ます。

いちばん上に、いまいる場所（または選んだ地点）に近い観測地点の値を、健康への影響の色（良い方から 緑・黄・薄いオレンジ・濃いオレンジ・赤・紫・黒）で出します。地点・指標・比べ方は「詳細設定」で変えられます。

WAQI のトークンを入れる（任意）

WAQI（aqicn.org）の API は個人ごとのトークンが必要です（無料で取得）。入れると、各地点の現在値を WAQI から取得して最新の点として重ねます。WAQI の無料 API は過去の履歴を返さず、利用条件でデータを貯めて再配布することも認められていないため、それ以前は模擬値のままです。トークンはこのブラウザだけに保存されます。

基準の色帯：US AQI は米国環境保護庁（EPA、2024年改定）の区分（良好 緑／普通 黄／敏感な人に良くない 薄いオレンジ／健康に良くない 赤／非常に良くない 紫／危険 黒）、API（マレーシア）・PSI（シンガポール）は 0–50 良好 緑／51–100 普通 黄／101–200 健康に良くない 赤／201–300 非常に良くない 紫／301以上 危険 黒、PM2.5 の1時間値は NEA の4段階（0–55 緑／56–150 濃いオレンジ／151–250 赤／251以上 紫、µg/m³）です。同じ言葉の区分は、指標が違っても同じ色にしています。時刻はすべてマレーシア・シンガポール時間（UTC+8）です。

模擬値は、地域ごとの平常値・日内変化・ヘイズの発生を組み合わせた乱数（再現できる種付き）で作っています。実測と取り違えないよう、グラフと表で「模擬」と表示します。 · ASEAN データエクスプローラー（Sea basic）
