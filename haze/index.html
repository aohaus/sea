WAQI のトークンを入れる（任意）

WAQI（aqicn.org）の API は個人ごとのトークンが必要です（無料で取得）。入れると、各地点の現在値を WAQI から取得して最新の点として重ねます。WAQI の無料 API は過去14日の履歴を返さないため、それ以前は模擬値のままです。トークンはこのブラウザだけに保存されます。

基準の色帯：US AQI は米国環境保護庁（EPA、2024年改定）の区分、API（マレーシア）・PSI（シンガポール）は 0–50 良好／51–100 普通／101–200 健康に良くない／201–300 非常に良くない／301以上 危険、PM2.5 の1時間値は NEA の4段階（0–55／56–150／151–250／251以上 µg/m³）です。時刻はすべてマレーシア・シンガポール時間（UTC+8）です。

模擬値は、地域ごとの平常値・日内変化・ヘイズの発生を組み合わせた乱数（再現できる種付き）で作っています。実測と取り違えないよう、グラフと表で「模擬」と表示します。 · ASEAN データエクスプローラー（Sea basic）
